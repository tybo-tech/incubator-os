  deliberately absent.
- **Service** (`VisitReportService`) — orchestration: lazy draft creation, status-gated content, atomic issue
  (snapshot → sign-off stamp → guarded transition), version-bound acknowledgement, `session_activities` audit.
- **Mapper** (`VisitReportMapper`) — full report DTO, empty draft shape, list summary.
- **Application layer** — 3 queries (`ListCompanySiteVisits`, `GetVisitReport`, `ListVisitVersions`) and
  5 commands (`SaveVisitReport`, `ManageVisitSection`, `ManageVisitSignoff`, `IssueVisitReport`,
  `AcknowledgeVisitReport`).
- **Endpoints** — `visit-list`, `visit-report`, `visit-versions`; `visit-save`, `visit-sections`,
  `visit-signoff`, `visit-issue`, `visit-acknowledge`; shared `sessions_visit_service()` in `_bootstrap.php`.
- **2.7** — `visitReportStatus` exposed on `SessionResponse`/`SessionSummary` via a light subquery join.
- **Responder** — structured validation messages may now carry a machine-readable code.
- **`feature.json`** — visit queries/commands declared (only what exists).
- **Tests** — `tests/SiteVisits.ps1`, 17 sections / **98 assertions**, all PASS.

## Decisions

- **No re-issue endpoint.** An issued report is frozen; the schema/service support a future re-issue
  (version increments, sign-off re-stamping) but none is exposed, so a second issue is always
  `VISIT_ALREADY_ISSUED`.
- **Version number is `MAX(existing)+1`**, not `current_version+1`, so a retry cannot reuse a version; the
  UNIQUE key is the backstop.
- **Issue order:** insert version row → stamp sign-offs → guarded status transition, all in one transaction.
- **Absent vs explicit-null:** a header field is only overwritten when its key is present, so callers can
  clear a field without clobbering others.
- **Snapshot takes the issued version explicitly** (fix): it previously read `current_version` before the
  transition and recorded `0`.
- **`visit-context.php` / `visit-export.php` deferred** to Phases 3/4; `feature.json` declares only what exists.
- **Funding remains untouched** by every Phase 2 endpoint.
