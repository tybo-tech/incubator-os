# Session 006 — Task Management: Sorting + Board View

Date: 2026-08-19

## Goal

Improve the Task Management page (`/tasks`):
1. Sort tasks so recently created appear first.
2. Add a modern Board (kanban) view alongside the existing List view, with a view toggle in the header.
3. Board columns are grouped by company (including an Unassigned column) so cards can be played with per company, with resizable column widths.

---

## Completed

- **Sorting**: Tasks are now sorted descending by `created_at` (falling back to `data.created_date`) so the most recently created tasks appear first at the top.
- **View Toggle**: Added a List/Board segmented toggle in the page header next to the "New Task" button.
- **Board View**:
  - Kanban-style columns grouped by **status** (To Do / In Progress / Done).
  - Each column shows a header (color dot, status name, task count) and drag & drop area.
  - Cards show title, status pill, priority accent (left border color), description (2-line clamp), due date, company tag, and assigned-to avatar initials.
  - Drag a card between columns to change its **status** (`NodeService.updateNode` persists the change; toast on error).
  - Column widths are resizable via a drag handle on the column header (240px–480px clamp).
- **Company Filter**: In board view, a dropdown next to the view toggle filters columns by company (`All Companies`, individual companies, or `Unassigned`).
- Existing filter tabs, statistics, list view, and modal CRUD preserved.

## Decisions

- Sorting keyed on `created_at` first, `data.created_date` as fallback — matches the API payload where `created_at` is the authoritative timestamp.
- Board groups by **status** (`todo` / `in_progress` / `done`) instead of company — company data was sparse, so status is the primary grouping.
- Company filtering is a dropdown in the header (only shown in board view): `All Companies`, per-company, or `Unassigned`.
- Drag-drop on the board changes the task **status** (persisted via `NodeService.updateNode`); uses `cdkDropListGroup` for full board drag UX.
- Column widths stored in component state (`columnWidths`), clamped 240–480px.
