## Goal

Analyse how the company detail area works (`/company/:id/*`), then:
move Directors off the Overview, make the Compliance Score editable, move Assessment next to Overview,
and give the Directors screen a proper editing + explainable-ownership experience consistent with
Financial Indicators.

## Completed

### Round 1 — structure

- Analysed the company shell: tab bar is driven solely by `companyTabs` in `CompanyShellComponent`; children are routes under `company/:id`.
- Documented every tab and where its data lives (`companies`, `nodes`, normalized tables).
- Established that the Overview Compliance Score is **derived**, not stored:
  `has_valid_bbbbee + has_tax_clearance + has_cipc_registration + (cipc_status === 'IN BUSINESS') / 4`.
- Established that the Assessment screen is **not connected** to those flags (writes `consolidated_assessment` nodes only).
- Moved the **Assessment** tab to position 2 (directly after Overview).
- Added a **Directors** tab (`/company/:id/directors`) and removed the roster from Overview (replaced with a summary + link).
- Added compliance editing to the Overview compliance card.
- Fixed a latent bug: `update-profile.php` defaulted a missing `name` to `''`, blanking the company name on partial updates.
- Normalised the CIPC comparison (`trim().toUpperCase()`) because stored values drift in casing/whitespace.

### Round 2 — directors, ownership, icons

- Rebuilt the **Directors** screen in the Financial Indicators visual language: page header + toolbar, 5 summary cards, an "Ownership checks" panel, and a data table.
- Added **Edit Director** (was missing): `update-director.php` + `UpdateDirector` use case + `UpdateDirectorRequest` + `UserRepository::update()`.
- Director form is now a **dialog** with the project contract: fixed header, scrollable body, fixed footer. It shows live derived values from the SA ID (DOB, age, gender, youth) and the ownership contribution with a green check / cross and the reason for each.
- Shared **SA ID parser** (`src/app/shared/utils/sa-id.ts`): 13-digit + **Luhn checksum** + date validity + gender + age. Verified against all 39 legacy IDs (all pass; the one 12-digit ID is correctly rejected).
- Added the same Luhn check to `DirectorSummary::isValidIdNumber()` so backend `idValid` and the UI agree.
- Ownership is now **explainable**: new `OwnershipSummary` projection returns flags + reasons + contributing director IDs; used by `GetDirectors` and `GetOverview`. Example reasons: "Set by Naledi Dube, Thabo Mokoena (Black).", "Age unknown for every director — capture a valid 13-digit SA ID", "No Black female director — Thabo Mokoena recorded without a female gender."
- Single source of truth for the ownership rules: `CompanyRepository::recalculateOwnership()` now maps rows through `DirectorSummary` (same helpers as `OwnershipSummary`).
- Director roster is now filtered to `role = 'Director' AND status = 'active'` — the same set the ownership calculation uses. `GetOverview` uses the same query, so counts can no longer disagree.
- Icons: migrated the tab bar, company shell header, overview cards and directors screens off Font Awesome / raw inline SVG onto `app-icon` + `ICON_PATHS`; added 16 semantic paths (home, trophy, chart-bar, shield-check, user-group, banknotes, …) and multi-path support in `app-icon`.

## Decisions

- **Directors get their own tab** rather than living in BEE Compliance: BEE Compliance is node-based records and disconnected from `companies`.
- **Compliance editing lives on the Overview card** because that card feeds the Compliance Score metric.
- **Ownership stays derived, never typed.** Race drives black ownership (an SA ID does *not* encode race — the ID only gives DOB, gender and a checksum), gender drives black-women ownership, and a valid ID drives youth.
- **Assessment stays unwired for now** (manual decisions: mapping SARS answers onto company flags would overwrite manual edits).
- **Invalid-but-non-empty SA ID blocks save**; an empty ID is allowed because youth status may legitimately be unknown.
- **Queries stay side-effect free**: `GetDirectors`/`GetOverview` compute live ownership but only mutations persist the flags.
