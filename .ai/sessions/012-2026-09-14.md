## Decisions

- **One shared stylesheet for both workspaces** (global `@layer components`, `sw-` namespaced) instead of duplicating ~13 kB into each component. This keeps the two pages literally consistent, and removed the need to loosen the component-style budget (which was reverted).
- **GPS detail moved from inline row expansion to a popup with view ↔ edit modes** — per the request. The popup is the single place for provenance, tasks, and updates, reducing the table to a scannable grid and giving edit a natural home.
- **Left expand chevrons removed** — a row click opens the popup; the right-side pencil opens the same popup (view) where Edit is one click away.
- **`Source` column** (Linked / Not linked) surfaces the SWOT provenance at a glance, mirroring the "link target" concept from the SWOT side.
- **Grouped view groups by category** for GPS (vs by type for SWOT) — category is the GPS equivalent axis.
- **Client-side filter/sort/search** over the loaded set (same as SWOT); server-side remains the scale-up path.
