## Decisions

- **Migrate on prod as-is, no heuristic linking** — every target enters as `legacy_unlinked`; humans link on-screen. This matches the product intent and keeps provenance honest (no guessed `source_key` links).
- **Only the latest node per company+type migrates** — company 11's 38 autosave versions collapse to 1 analysis; the rest are flagged as duplicates in the audit summary, not merged.
- **Preview gate before prod migrate** — prod preview numbers were required to match the local clone dry-run exactly before confirming. They did (`50/12 · 80/5 · 62/9 · 62`).
- **Prod `Database.php` is authoritative** — `setServer()` → `rbttaces_api`; the local repo copy (which calls `setLocal()`) must never overwrite it. Prod-only `common/common.php` treated the same.
- **`nodes.token` repair recorded as a dated migration patch** — kept guarded/idempotent so it is safe on local (where it is a no-op) and on other environments.
- **Empty legacy submissions are imported as empty analyses** — not filtered, so the archive stays faithful; flagged as cleanup candidates instead.
- **Test artefacts reverted** — the manual link was unlinked so prod remains exactly as migrated (`62 legacy_unlinked`, 0 linked) for real users to link themselves.
