## Decisions

- **Verification is SA-only.** No Coach role exists; the coach path is deferred and no role string was invented (explicit instruction).
- **`reject` added** as a lifecycle action (status `rejected`, **no snapshot**) — implied by the `rejected` enum and the required validation case.
- **Verified/decided records are immutable**; corrections go through `revoke` (reason required) or `supersede` (new draft, original preserved).
- **Evidence is append-only**: add allowed on drafts and verified records; delete is draft-only (`409` once decided).
- **Races**: `SELECT … FOR UPDATE` + status re-check + snapshot+status in one transaction, backed by a DB functional unique index on metric snapshots.
- **Ineligible measurements fail verification** (`configured` + `eligible_for_achievement` required); the record is left unchanged and no snapshot is written.
- **Identity is never trusted from input**; `recorded_by`/`verified_by`/`verification_status` are ignored if posted.
- **Same-company** enforced for the linked target and for supersede; a superseding draft inherits the original's company.
- **Schema correction**: functional index used because a stored generated column deriving from the FK column `achievement_id` is rejected by InnoDB (error 1215).
