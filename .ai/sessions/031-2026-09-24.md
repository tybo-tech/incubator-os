## Decisions

- **State is server-side single-use, not stateless HMAC.** Amends Architecture Decision 10: a signature cannot enforce one-time consumption. Only the SHA-256 hash of the state is stored.
- **Fixed redirect URI only.** The redirect URI is read from config; a client-supplied value is never used.
- **Safe redirect vocabulary.** The callback's browser redirect may carry only `connected`, `denied`, `scope_missing`, `invalid`, `account_mismatch` or `failed` plus a validated internal path.
- **Connection is strictly per-actor.** No admin path returns another user's tokens; `assertOwnConnection()` makes this explicit.
- **Audit-preserving disconnect.** The row is hard-deleted only when nothing references it; otherwise it becomes `disconnected` with tokens cleared.
- **Account mismatch is a controlled state**, never a silent reassignment of published mappings.
- **Fake selection honours the gitignored config flag** (`use_fake`) as well as `GOOGLE_FAKE`, so tests never mutate the container environment and can never cause a real call.

### Defects found and fixed during Phase 2 testing

1. `GoogleApiClientFactory` only checked `getenv('GOOGLE_FAKE')`, so the HTTP path silently used the real cURL client. Now it also honours `google_use_fake()`.
2. `GoogleConnectionRepository::upsertConnected` passed tenant/user params to an UPDATE with no such placeholders (PDO HY093). Params are now scoped per branch.
3. `config/google.local.php` written with a UTF-8 BOM emitted output before headers, making every status fall back to 200. Rewritten without a BOM; all changed files are BOM-free.
