## Decisions

- **AAD binding:** each ciphertext is authenticated against `TokenCipher::aad(tenant, user, provider, purpose)`, so a token cannot be replayed into another user's row or reused for a different secret type.
- **Separate storage columns:** ciphertext, nonce, tag and key version are distinct columns — never a concatenated blob — so they can be inspected and rotated independently.
- **Fail-closed everywhere:** wrong key, tampered ciphertext, unknown key version, malformed payload and missing config all refuse; corrupted plaintext is never returned.
- **Single logging seam:** `GoogleLog` (redacted) is the only logging path in the capability; `SecretRedactor` registers the live client secret at construction so it is stripped even if a future caller logs a payload containing it.
- **`GoogleApiException` reason codes:** transport-agnostic; callers branch on `reason()`, never on a message string. `requiresReconnect()` centralises `invalid_grant`/`unauthorized`.
- **`GOOGLE_FAKE=1` factory seam:** the only place transport is chosen; tests never touch the network.
- **No Composer / `google/apiclient`:** consistent with Sprint-010 Architecture Decision 1; the `GoogleApiClient` interface isolates the choice.
