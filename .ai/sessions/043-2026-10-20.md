- **Financial month semantics (blocking).** `data.meta.month` is a **calendar month** (`1 = January`),
  evidenced by `financial-form.component.ts:115-120` and
  `AnnualReportResponse::monthNameToNumber`. `MONTH_ORDER` is display order only. Sprint 015's
  `1 = March` rule would have shifted every recency score by two months; rewritten in the contract
  table, the rule paragraph, the component reason codes and task 2.1/2.2.
- **`FinancialSummary.capturedMonths` is not a completeness signal.** It counts months where the
  value is `> 0` (`CompanyRepository.php:66-84`); `activeMonths` is `row_count × 12`. Removed from the
  Discovery and Sprint 015 guidance; monthly recency now uses the `nodes` financial-indicator rows.
- **`description` nuance.** It is already in `CompanyRepository::WRITABLE` (`:150`); only the request
  DTO, command mapping and UI are missing. Sprint 013 now explicitly **supersedes Sprint 011 tasks
  3.1 and 5.10**, and those tasks are annotated in `Sprint-011.md` so they are not implemented twice.

- **Compliance validity is ambiguous.** Defined effective validity as boolean flag **AND** the

  `has_cipc_registration`; added reason codes.
- **Wrong paths / conventions.** Industry API is `api-nodes/industry/` (singular) and the tree comes
  from `list-industry-tree.php`; verification SQL lives in `docs/deployment/`, not
  `migrations/deployment/`; migration run orders **#29–#32** are reserved (012 already holds
  #27–#28) and each sprint now has a README-row task.
- **Tab order.** Corrected to `Overview → Profile → Assessment → Directors` (insert Profile at

### Security incident (new)

Created `.ai/sprints/Incident-001-mail-relay.md`:

- `api-incubator-os/mail/` is a **self-contained mini-app** (`mail/config/`, `mail/vendor/` with
  PHPMailer) deployed at `mail.rbttacesd.co.za`, called **directly from the browser**
  (`email.service.ts:22`).
- It is an **unauthenticated open relay** with a hardcoded BCC, no rate limit, and dead escaping
  (`htmlspecialchars` immediately overwritten).
- SMTP credentials are committed in `mail/send.php`; a production DB password is committed in
  `config/Database.php`. **Rotation is mandatory**; moving the values is not sufficient.
- The original Sprint 014 plan ("require an authenticated session on `send.php`") was not
  implementable cross-origin. Rewritten to: browser → API proxy → mail host with a shared secret and
  allow-list, config at `mail/config/mail.php`, escaping fixed, never-upload list extended.
