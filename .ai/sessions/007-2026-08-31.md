## Decisions

- **Preserve `nodes` as archive** — migrator is read-only on `nodes`; new tables are the operational source of truth. This avoids inheriting 38 duplicate SWOT autosaves for company 11 — only latest `updated_at` row is migrated, rest flagged in `duplicates_flagged`.
- **`is_current` uniqueness at app layer** — not a partial unique index (MySQL doesn't support it cleanly). `SwotAnalysis::clearCurrentForCompany()` inside transaction ensures only one live dashboard analysis per company.
- **`owner_label` + nullable `owner_user_id`** — legacy `assigned_to` values like `Owner`/`CFO`/`Ndu`/`Finance Team` are not FK-safe; preserve text in `owner_label` while allowing later resolution to real user FK.
- **Category on row, not container** — GPS `category` is a column on `gps_targets`, not a JSON container. `SELECT * FROM gps_targets WHERE company_id=? ORDER BY category, due_date` replaces the old `$data[category].targets[]` traversal; frontend groups the result.
- **Many-to-many `gps_target_sources`** — not a direct `swot_item_id` FK on `gps_targets`, because one target can arise from multiple findings (e.g., weakness “No accounting system” + threat “Tightening compliance” → one target “Implement compliant accounting”). Default `source_type=legacy_unlinked` until mentor links via UI; `source_key` treated as migration hint only.
- **`manual_progress_percentage` vs `progress_mode=metric/tasks`** — sprint 1 supports `manual` + `tasks`; `gps_target_metrics` schema is present but wiring to `metric_records` is Sprint 006 (needs `metric_types` + `metric_records` joins).
- **Junk filtering at migration** — `<3 chars`, pure numeric (`1`,`12`,`123`), single-char repeats, placeholder `S`/`SGi`/`Analyze your business…` are skipped and counted in `items_skipped_empty` rather than polluting the normalized tables.
- **Idempotency** — `legacy_node_id` check for `swot_analyses` and `company+category+description` check for `gps_targets` prevent double-insert on re-run; `clearForCompanies()` provided for intentional re-migration.
