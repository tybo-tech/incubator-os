# Session 039

Date:
2026-10-02

## Goal

Fix the production bug where logged-in users were silently signed out after ~24 minutes and saw
`Unauthorised — no active session. Please log in.` on the SWOT workspace (`company/:id/swot-v2`),
followed by a redirect to `/login` on refresh.

---

## Completed

- Root-caused the forced logout: the app never overrode PHP's default `session.gc_maxlifetime`
  (1440 seconds = 24 minutes), so the **server** garbage-collected the session while the browser
  cookie and the Angular localStorage `currentUser` still looked logged-in. Any API call after that
  returned `401` from `auth_require_user` (all SWOT/normalized endpoints use it), and
  `AppShellComponent.ngOnInit → validateSession()` redirected to `/login` on refresh.
- Added `helpers/Session.php` — the single source of session config:
  - `APP_SESSION_LIFETIME = 86400` (24 hours).
  - `app_session_start()` starts the session once with a 24h cookie **and** sets
    `session.gc_maxlifetime` / `session.cookie_lifetime` to match.
- Replaced the five duplicated inline `session_set_cookie_params(['lifetime' => 0, ...])` blocks:
  - `helpers/AuthGuard.php` (auto-start + `auth_require_user`).
  - `api-nodes/user/login.php`, `validate-session.php`, `logout.php`, `invite-user.php`.
- `logout.php` now also expires the client session cookie (needed now that it is persistent).
- Added `api-incubator-os/.user.ini` with `session.gc_maxlifetime = 86400` and
  `session.cookie_lifetime = 86400` for cPanel/LiteSpeed hosts whose session-cleanup cron ignores a
  per-request `ini_set`.
- Verified `php -l` clean on all touched files.

## Decisions

- **24 hours** is the shared session lifetime, in one constant (`APP_SESSION_LIFETIME`) so the cookie
  and the server GC cannot drift apart again.
- Session configuration is centralised in `helpers/Session.php`; endpoints must call
  `app_session_start()` instead of hand-rolling `session_set_cookie_params`.
- Ship a `.user.ini` in addition to the runtime `ini_set`, because shared hosts may run session GC
  from cron and ignore per-request overrides.
